**Pewiri Emeralds** es una plataforma moderna diseñada para la visualización de catálogos de joyería fina. El proyecto está construido bajo una arquitectura de monorepo, separando la lógica de cliente (Frontend) de la gestión de contenidos y stock (Backend).

## 🚀 Características

- **Catálogo Dinámico:** Visualización de productos con gestión de stock en tiempo real.
- **Arquitectura Monorepo:** Organización limpia con carpetas `/frontend` y `/backend`.
- **Panel de Administración:** Gestión de inventario intuitiva mediante Strapi CMS.
- **SEO Optimizado:** Renderizado eficiente con Next.js para mejorar el posicionamiento.
- **Diseño Responsivo:** Experiencia fluida en dispositivos móviles y escritorio.

## 🛠️ Stack Tecnológico

### Frontend
- **Framework:** Next.js (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
  
### Backend
- **CMS:** Strapi (Headless CMS)
- **Base de Datos:** SQLite
- **Hosting sugerido:** Vercel (Frontend) y Strapi Cloud/Render (Backend)

## 📦 Configuración

### Requisitos previos
- Node.js v18 o superior
- NPM o Yarn
